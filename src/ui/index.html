准备 ApkStart 运行时

ApkStart 自带完整的安卓运行时（adb + QEMU + Android-x86），不需要安装任何第三方模拟器。

安装 Android 到虚拟磁盘

虚拟机窗口已打开。按下面 6 步操作一次，之后 ApkStart 会直接从磁盘启动，不再需要镜像。

  1. 启动菜单：用 ↓ 选到 Installation - Install Android-x86 to harddisk，回车
  2. Choose Partition：选 Create/Modify partitions；询问是否使用 GPT 时选 No
  3. cfdisk 分区：New → Primary → 容量直接回车 → Bootable → Write → 输入 yes → Quit
  4. 格式化：选 vda1 → 提示格式化时选 ext4 → Yes
  5. 引导与系统：Install GRUB 选 Yes；Install /system as read-write 选 Yes
  6. 完成：进度到 100% 后点下面的「我已安装完成」（ApkStart 会自动重启并接管）

如果之后提示 adb 未连接：在虚拟机窗口按 Ctrl+Alt+F1 进入终端，执行 setprop service.adb.tcp.port 5555、stop adbd、start adbd， 再按 Ctrl+Alt+F7 回到图形界面。
