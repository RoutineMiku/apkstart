Install Android to Virtual Disk

VM window is open. Follow these 6 steps once, then ApkStart boots directly from disk without an ISO.

  1. Boot Menu: Use ↓ to select Installation - Install Android-x86 to harddisk, press Enter
  2. Choose Partition: Select Create/Modify partitions; choose No when asked to use GPT
  3. cfdisk Partitioning: New → Primary → press Enter for size → Bootable → Write → type yes → Quit
  4. Formatting: Select vda1 → choose ext4 when prompted → Yes
  5. Bootloader & System: Install GRUB choose Yes; Install /system as read-write choose Yes
  6. Finish: When progress reaches 100%, click "I have completed installation" below

If adb shows disconnected later: press Ctrl+Alt+F1 in VM window for terminal, run setprop service.adb.tcp.port 5555, stop adbd, start adbd, then press Ctrl+Alt+F7 to return to GUI.
