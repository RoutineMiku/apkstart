Install Android to Virtual Disk

The VM window is open. Follow these 6 steps once, and ApkStart will boot directly from disk without needing the image again.

  1. Boot Menu: Use ↓ to select Installation - Install Android-x86 to harddisk and press Enter
  2. Choose Partition: Select Create/Modify partitions; choose No when asked about GPT
  3. cfdisk Partitioning: New → Primary → press Enter for size → Bootable → Write → type yes → Quit
  4. Format: Select vda1 → choose ext4 → Yes
  5. Bootloader & System: Choose Yes for Install GRUB; choose Yes for Install /system as read-write
  6. Finish: When progress reaches 100%, click "I've Finished Installing" below (ApkStart will reboot and take over automatically)

If adb is not connected afterward: press Ctrl+Alt+F1 in the VM window to open a terminal, run setprop service.adb.tcp.port 5555, stop adbd, start adbd, then press Ctrl+Alt+F7 to return to the GUI.

System Preflight · Auto-Config
Checks this machine: CPU virtualization status, Windows Hypervisor Platform, GPU model & VRAM, RAM, and OS version. Auto-tunable settings (RAM / cores / resolution / renderer) are applied directly and saved as a driver; admin-only fixes provide a button; BIOS settings explain what to change.
Drivers · Compatibility Patches
Some machines need custom launch flags to run properly (older GPUs with low GLES, no hardware acceleration, or driver crashes with hardware rendering). A driver is a JSON file declaring "which machines to match" + "which launch flags to override". You can write, import, and share them. Drivers only modify whitelisted launch options and never execute code; unmatched drivers do nothing.
