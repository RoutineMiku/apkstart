一次就好

开机自启、自动部署、零参数：首次启动会在后台自动准备运行时，按这台电脑的内存、CPU、显卡和加速状态自适应，失败自动换方案重试。这里只有一个步骤，通常不用点任何按钮，也不需要安装任何第三方模拟器。

安装 Android 到虚拟磁盘

虚拟机窗口已打开。按下面 6 步操作一次，之后 ApkStart 会直接从磁盘启动，不再需要镜像。

  1. 启动菜单：用 ↓ 选到 Installation - Install Android-x86 to harddisk，回车
  2. Choose Partition：选 Create/Modify partitions；询问是否使用 GPT 时选 No
  3. cfdisk 分区：New → Primary → 容量直接回车 → Bootable → Write → 输入 yes → Quit
  4. 格式化：选 vda1 → 提示格式化时选 ext4 → Yes
  5. 引导与系统：Install GRUB 选 Yes；Install /system as read-write 选 Yes
  6. 完成：进度到 100% 后点下面的「我已安装完成」（ApkStart 会自动重启并接管）

如果之后提示 adb 未连接：在虚拟机窗口按 Ctrl+Alt+F1 进入终端，执行 setprop service.adb.tcp.port 5555、stop adbd、start adbd， 再按 Ctrl+Alt+F7 回到图形界面。

随 Windows 登录常驻托盘，双击桌面图标秒开应用，无需手动启动。
应用窗口
随时按 F11 或右键托盘切换；全屏只放大窗口，不改变画面比例，切换不重启应用。
窗口模式下可拖动边框任意缩放；这里调的是 Android 内部渲染尺寸，越小越省性能。
鼠标键位
模拟器原生把左键当成手指点击，按住拖动就是滑动，无需额外设置。
模拟器默认把右键也当成一次点击（容易误触）。开启后右键只执行返回，不再触发点击。
平滑模式把一小段时间内的滚动合并成一次滑动手势，避免逐格抽搐，也不会每格都拉起一个 adb 进程。
侧键映射需要全局鼠标钩子。钩子只在 ApkStart 应用窗口处于前台时安装，失焦或关闭立即卸载，不会拖慢桌面。
以上映射只在应用窗口前台生效；切回桌面或关闭窗口后，鼠标行为完全恢复 Windows 原生。
性能与轻量容器
把安卓虚拟机限制在 2–3 个 vCPU 并降低进程优先级，CPU 优先让给 Windows 桌面。关掉后按机器配置分配更多核心，安卓更猛但主机会明显变卡。
没有应用窗口时，容器一律自动降到最低优先级停放。
额外禁用 Play 商店、设置向导、打印服务等后台包，只留打开应用必需的环境。若遇到应用提示缺少 Google Play 服务，关掉此开关会自动恢复。
安卓环境只开机一次并常驻；之后打开应用不再重跑整个系统，只启动该应用并停掉其他应用进程。关掉最后一个窗口会清后台、停放容器，下次点开仍是秒进。
